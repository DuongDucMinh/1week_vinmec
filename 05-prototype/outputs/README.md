# Báo cáo kiểm thử và triển khai

Thư mục này lưu các báo cáo JSON và bằng chứng kiểm tra phần mềm. Toàn bộ ảnh giao diện và sơ đồ minh họa đã được chuyển sang thư mục [00-luong-he-thong-qua-anh ở root](../../00-luong-he-thong-qua-anh/README.md).

Xem [luồng 7 bước](../../00-luong-he-thong-qua-anh/README.md), [ảnh bổ sung](../../00-luong-he-thong-qua-anh/bo-sung/README.md) hoặc [ảnh lưu trữ](../../00-luong-he-thong-qua-anh/luu-tru/README.md). [Danh mục đường dẫn](../../00-luong-he-thong-qua-anh/danh-muc-anh.json) giúp đối chiếu tên tệp trong các báo cáo lịch sử.

Bộ kiểm thử ghi ảnh giới thiệu trực tiếp vào thư mục luồng ảnh qua [`ui-artifacts.ts`](../tests/e2e/ui-artifacts.ts). Ảnh lỗi, trace và HTML report tạm thời vẫn là dữ liệu chẩn đoán cục bộ, được Git bỏ qua.
